# CodexFlow

[English](SKILL.md) · **Русский**

Это русская документация к [исполняемому Skill](SKILL.md). Codex загружает английский `SKILL.md`.

Вызов принимает задачу, необязательную глубину `--quick|--standard|--full`, профиль `--profile efficiency|performance|speed` и повторяемые параметры `--set KEY=JSON`. Команды `config`, `history`, `status [run-id]` и `resume <run-id>` работают внутри запроса к Codex. Для задачи, начинающейся с имени команды, укажите режим.

1. Сохраните задачу в UTF-8 и вызовите `begin`. Скрипт проверит настройки и обе главные роли, прочитает каталог и создаст запуск. Передавайте фактическую модель и доступность только если эти данные предоставил клиент. Используйте возвращённые ID и ревизию.
2. Оцените задачу по масштабу, ограничениям, риску регрессий и необходимости независимой проверки. Указанный пользователем режим сохраняется. Подробности в [этапах](references/pipeline.ru.md).
3. В QUICK запишите классификацию и обоснованные пропуски через `record`. Поля каждого элемента — `stage`, `status` и `result`. Объект допускается для завершённой CLASSIFICATION, остальные результаты — непустые строки. STANDARD и FULL используют последовательные `checkpoint`.
4. Внесите изменения, проверьте diff и запустите проверки проекта. QUICK может сохранить смежные результаты пакетом. Перед долгими тестами сохраните реализацию отдельно. Необходимые тесты или ревью, которые не удалось выполнить, блокируют следующий этап.
5. Делегируйте отдельную работу согласно политике. Используйте нативных субагентов, свежий контекст и компактное задание. После тестов проведите обязательное ревью. Разрешён один автоматический цикл исправлений с повтором затронутых проверок.
6. Сохраните итог с результатами, фактическими агентскими запусками, подтверждёнными моделями и известными ограничениями. Потребление токенов указывайте только по данным клиента.

Для продолжения используйте сохранённую политику и сверяйте фактические файлы с артефактами. Подробности в разделах [профили](references/profiles.ru.md), [модели](references/models.ru.md) и [роли](references/agents.ru.md).
