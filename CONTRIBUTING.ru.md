# Участие в проекте

[English](CONTRIBUTING.md) · **Русский** · [Главная](README.ru.md)

Issues и pull request можно писать на любом из двух языков. Укажите версии клиента Codex и плагина, ожидаемое поведение и небольшой пример, на котором проблема повторяется. Уберите приватные данные и пути из цитат.

Запустите проверки из корня репозитория:

```sh
python3 -m unittest discover -s tests -v
python3 scripts/validate_package.py
```

При изменении поведения обновите документацию на обоих языках. Английский `SKILL.md` остаётся точкой входа для Codex. Изменения модельной политики, переходов и установщика проверяйте целевыми регрессионными тестами. Недоступность моделей и ошибки каталога можно симулировать. Для реальной проверки Codex используйте отдельный проект.

В pull request опишите заметное пользователю изменение, выполненные проверки и известные ограничения. Правила версий и тегов есть в [инструкции релиза](docs/releasing.ru.md).
