# Исследование совместимости

[English](research.md) · **Русский** · [Главная](../README.ru.md)

Первоначальное исследование от 2026-11-17. Ниже описана архитектура на момент первой сборки. Текущие правила моделей и состояния описаны в [архитектуре](architecture.ru.md). Локальный `codex-cli 0.169.0`; проверены только help/version, вложенные LLM-сеансы не запускались.

Официальные источники:

- [Skills](https://learn.chatgpt.com/docs/build-skills): формат SKILL.md и явный выбор через `$` в Codex.
- [Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents): нативная делегация, модели и наследование, ограничения клиентской поверхности.
- [Plugin packaging](https://developers.openai.com/plugins/build/plugins): поддерживается compatibility manifest `.codex-plugin/plugin.json`; marketplace содержит пути относительно своего корня.
- [Plugins](https://learn.chatgpt.com/docs/plugins): доступность установки зависит от клиента; IDE может использовать standalone skill.

Выбран поддерживаемый compatibility package со Skill, без MCP и hooks: задача не требует собственного сервера или дополнительных разрешений. Ролевые документы — инструкции handoff, а не выдуманный реестр Plugin API. Python управляет только артефактами и проверяет политику. Классификация и выполнение остаются у Codex.

Ограничения: нет переносимого skill API для смены модели главного агента, проверки цен/квот, жёсткого токенного бюджета, принудительного read-only child или одинаковой схемы spawn во всех клиентах. Реальная доступность и фактическая выбранная модель проверяются по текущим инструментам. Дефолтная политика требует явного разрешения модели родителя; премиальные модели не определяются по автоматически обновляемому прайс-листу, поэтому их нельзя добавлять в пользовательский allowlist. Запрет Astra проверяется независимо от allowlist; неизвестные алиасы нельзя достоверно разрешить без данных клиента.

План реализации: skill и ролевые контракты → политика моделей → атомарное состояние и продолжение → тесты режимов/ошибок/восстановления → изолированный реальный smoke test → документация установки. Автоматической установки в пользовательский Codex и глобальных изменений нет.
