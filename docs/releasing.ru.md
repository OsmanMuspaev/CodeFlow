# Подготовка релиза

[English](releasing.md) · **Русский** · [Главная](../README.ru.md)

Теги имеют вид `vMAJOR.MINOR.PATCH`. Версия без `v` должна совпадать с [манифестом плагина](../plugins/codeflow/.codex-plugin/plugin.json). Изменения для пользователя запишите в оба changelog. Minor добавляет совместимые возможности, patch исправляет поведение, major обозначает несовместимые изменения. Опубликованные теги остаются на исходных коммитах.

1. Обновите манифест, бейджи README и оба changelog. Запустите тесты и валидатор пакета.
2. Проверьте установку в чистом окружении. Соберите marketplace командой `python3 scripts/prepare_marketplace.py dist/codeflow-v1.4.0`, указав нужную версию и новую папку.
3. Закоммитьте проверенные файлы и создайте аннотированный тег. Проверьте адрес репозитория и отправьте `main` и нужный тег.
4. GitHub Actions запускает тесты на теге и собирает ZIP. Скачайте архив, приложите его к черновику релиза для этого тега и добавьте заметки из changelog. Проверьте архив перед публикацией черновика.

История репозитория начинается с `v1.3.0`. Более ранние версии были локальными сборками и описаны в changelog.

Для первой публикации создайте пустой репозиторий на GitHub, подставьте его URL и выполните:

```sh
git remote add origin https://github.com/OWNER/CodeFlow.git
git push -u origin main
git push origin v1.3.0
```

В архиве лежит папка с каталогом marketplace, плагином и лицензией. Распакуйте её и передайте путь к ней команде `codex plugin marketplace add`.
