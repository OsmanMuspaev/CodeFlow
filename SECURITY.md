# Security

**English** · [Русский](SECURITY.ru.md) · [Home](README.md)

Please use the repository's private vulnerability reporting channel if enabled or contact a maintainer privately. Include the affected version, impact and a minimal reproduction. Use public issues for ordinary bugs.

Treat task files, reports and logs as project data. Share only the minimum needed to reproduce a problem and remove credentials, private paths and source code where possible. CodeFlow uses the client sandbox and approval settings. Its read-only agent instructions are not a separate sandbox.
